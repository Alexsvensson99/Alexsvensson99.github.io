Colors and palettes

Why might a color look different?

Tintward uses sRGB. Images with other color profiles, such as Display P3, are converted before a color becomes a HEX value. Transparent pixels are composited against white.

Display settings, brightness and your surroundings can affect how a color looks. The HEX value describes its sRGB channels.

What does locking the original do?

The original color stays exact in the role for your chosen use: accent for a button, text for text, and background for a background. You cannot edit that role manually while the original is locked.

A contrast suggestion does not become your current theme until you apply it. Export uses the current theme, including manual edits.

What does the AA label mean?

It assesses the contrast of a color pair. Normal-sized text needs at least 4.5:1. Tintward checks text on accent, text on background and text on surface.

A passing combination does not mean the entire interface is accessible. Size, content, focus order and other properties still need to be reviewed.

How do I keep a palette and a backup?

Save the palette in your library. After editing an existing palette, save your changes to update the stored version.

The library's JSON export is intended for backup and reimport. CSS, SwiftUI and the Xcode color catalog are intended for code projects and do not replace a full library backup. Check that a file has actually been saved before deleting anything.

An image or export will not open. What can I do?

Check that the image is HEIC, JPEG or PNG and available on your device. A cloud file may need to be downloaded by its system provider.

If the system picker gets stuck, cancel and try again. If the problem continues, email the location, file type and error message. An export should not be treated as saved until saving has been confirmed.

Your data

Color work stays on your device.

The app has no sign-in, advertising or analytics. Original images are not stored in the palette library. You choose when content is copied, shared or exported.
