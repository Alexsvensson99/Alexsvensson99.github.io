Who is it for?

For streamers, workshop hosts, and producers using OBS Browser Sources who want to configure overlays locally.

What you can do

  • Choose from 16 independent overlays for starts, breaks, speakers, and agendas.
  • Use Studio or Signal themes with two formats and transparent or opaque-outside-card backgrounds.
  • Preview session text, deadlines, and agenda highlights before download.
  • Download replacement HTML or a complete kit and save a portable project.

How it works

  1. 01

    Open START.html, choose an overlay and format, and enter the session details.

  2. 02

    Preview the result and download the HTML file or a complete kit.

  3. 03

    Add the file as a Local file in an OBS Browser Source, set matching dimensions, and refresh the source after replacement.

Frequently asked questions

Does it work offline?

Yes. Open START.html from the downloaded folder. No account, server, or cloud connection is needed.

How do I use the file in OBS?

Create a Browser Source, select Local file, choose the downloaded HTML file, set matching dimensions, and refresh after replacing the file.

Does Static stop the countdown?

No. The countdown continues to update; Static only stops decorative motion.
