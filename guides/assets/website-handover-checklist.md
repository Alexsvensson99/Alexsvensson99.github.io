# Free Website Handover Checklist

Use this file after a website delivery to prepare a clear client package. Adapt it to the actual project. Do not put passwords, API keys, recovery codes, private notes, or unselected working files in the client version.

## Project record

- [ ] Website name and public URL recorded
- [ ] Delivery date recorded
- [ ] Delivered pages, features, and selected attachments listed
- [ ] Client organisation named as the owner of its own material
- [ ] Open issues listed separately from completed work

## Ownership and access references

- [ ] Domain owner and renewal contact identified
- [ ] Hosting owner and support route identified
- [ ] Website account access-request route recorded
- [ ] Analytics, email, form, payment, or other service owners listed only where they apply
- [ ] No credentials or secret values included
- [ ] Client knows who can approve access changes

## Content and editing notes

- [ ] Routine tasks explained in plain language: edit text, replace an image, publish an event, request a change, report a problem
- [ ] Image guidance includes the preferred source, crop or size where known, and a reminder to check the page after publishing
- [ ] Navigation and page-structure decisions recorded
- [ ] Third-party assets or licences the client needs to maintain are identified
- [ ] Instructions point to current official documentation when service-specific steps can change

## Support and open work

- [ ] Support route and useful defect-report details recorded
- [ ] Included support scope or period recorded, if agreed
- [ ] New work is separated from defect reports
- [ ] Every open issue has an owner and next action
- [ ] No claim is made that the website is secure, backed up, legally compliant, or ready for every future launch unless separately verified by the responsible party

## Client package and acceptance

- [ ] Client-facing handbook reviewed without internal comments
- [ ] Markdown handover copy included if the client needs an editable record
- [ ] Checklist shows completed and open items honestly
- [ ] Only selected instruction images and attachments included
- [ ] Client can confirm receipt and identify a missing handover item

## Notes

This checklist is a working template, not a security audit, backup confirmation, legal review, or service guarantee. You may copy and adapt this free template for your own client work.
