PkgLift

Ett kommandoradsverktyg som hjälper native Xcode-projekt att migrera från CocoaPods till Swift Package Manager – stegvis och utan att gissa.

  • Analyserar projektet och bygger en granskningsbar migrationsplan.
  • Ändrar bara beroenden som har tillräcklig, verifierad evidens.
  • Distribueras via signerad release och Homebrew.
